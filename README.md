# Frontend Engineering Lab 🧪

A curated collection of polished UI components, JavaScript logic utilities, and algorithmic solutions. This repository serves as both a practice ground for interview preparation and a showcase of clean, performant frontend code.

## 🚀 Categories

### 🎨 UI Components
Focusing on accessibility (A11y), performance, and modern CSS techniques.

### ⚙️ JavaScript Logic
Deep dives into the core of the language and common FE-specific challenges.

### 🧩 Algorithms
Frontend-focused data structures and algorithmic problem-solving.

## 🛠️ Tech Stack
- **Languages:** JavaScript (ES6+), TypeScript, HTML5, CSS3 (SCSS/Tailwind)
- **Frameworks:** React, Next.js
- **Testing:** Jest, React Testing Library

## 📝 How to Use
Each folder contains its own `README.md` with specific instructions on how to run the code or the logic behind the solution.
